# Nova AI Landing Page

Marketing site for **Nova AI** — an AI-native platform for circuit design, embedded development, simulation, and edge deployment.

## Features

- Responsive hero with animated pipeline visualization
- Core features section with hardware workspace imagery
- Scroll-driven glow and parallax effects
- Beta signup and product sections
- Mobile-friendly navigation

## Tech Stack

- [React](https://react.dev/) 19
- [TypeScript](https://www.typescriptlang.org/)
- [Next.js](https://nextjs.org/)
- [Framer Motion](https://www.framer.com/motion/)
- [Inter](https://fonts.google.com/specimen/Inter) & [Instrument Serif](https://fonts.google.com/specimen/Instrument+Serif) fonts

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Install

```bash
npm install
```

### Development

```bash
npm run dev
```

Open the URL shown in the terminal (default: `http://localhost:3000`).

### Build

```bash
npm run build
```

Build output is produced in the Next.js build directories; run `npm run start` to serve the production build.

### Preview production build

```bash
npm run preview
```

### Lint

```bash
npm run lint
```
